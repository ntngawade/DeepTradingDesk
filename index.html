How fields are read

Stock and execution timeframe come from the chart title. Setup comes from the higher-timeframe zone label: Y → YIT, H / HY → HYIT, Q → QIT, M → MIT, W → WIT, D → DIT. For example RB3-M means a monthly zone (MIT); a D chart title still means daily execution.

The reader captures marked prices and text annotations. It does not invent missing prices or interpret unmarked candle patterns. If a target is missing, you may explicitly use your configured reward ratio during review. No trade is armed by importing a chart.

Uses the English text-recognition component already built into this Windows computer. No Ollama, downloaded AI model, cloud API or external chart service. Chart images are held in memory for this session; clear the queue when finished.
